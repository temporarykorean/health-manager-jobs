## 검색과 화면

- 검색 키워드: 보건관리자, 보건 관리자, 산업간호사, 산업 간호사, 보건관리원, 사업장 간호사, 산업보건, EHS 보건, 안전보건.
- ALIO는 전체 검색(제목/응시자격/우대조건 등) 후 상세의 직무·자격 문맥을 확인합니다. 공개 목록의 최근 120일 진행중 공고를 키워드별 최대 100건 조회하고 중복 제거 후 최신 상세 최대 100건을 확인합니다. 한도/일부 접속 실패를 숨기지 않고 부분 수집으로 표시합니다.
- Greeting은 공통 목록 파서와 공개 페이지의 서버 렌더링 데이터로 여러 기업을 지원합니다. 현재 HYBE·DN오토모티브·11번가 연결, 관련 제목/직군 및 EHS 후보의 상세 최대 20건 확인. 무관한 제목의 모든 본문까지 검색하는 방식은 미구현입니다.
- 회사명, 제목, 지역, 상세 근무지, 고용형태, 게시일, 마감일, 원문 URL, 출처, 수집 시각 저장. 미공개 날짜/상세 근무지는 추정하지 않습니다.
- 고용형태 전체/정규직/비정규직/확인 필요, 지역 전체/서울/경기/인천/기타. 최신 게시일순이 기본이며 게시일 미기재는 최초 발견일을 사용합니다.
- 마감 공고 기본 숨김, 마감 공고 포함 옵션, 검색, 기기별 관심 저장, 원문 링크.
- 일반 현장직의 산업안전보건법 준수·기초 안전보건교육 이수 문구만으로 보건 공고로 분류하지 않습니다. 간호사 면허 기반 보건 직무에 집중하며 안전관리자·산업위생사 자체의 채용은 제외합니다.
- URL 추적값 제거와 공고 식별자를 포함한 원문 별칭으로 중복을 정리합니다. 회사/제목/근무지/게시일이 같은 공고도 정리하되 반복 채용의 날짜는 구별합니다.

## 분류 정확도의 범위

ALIO의 구조화된 고용형태 및 Greeting의 명시된 형태를 우선 사용합니다. 계약직/기간제/파견직/프로젝트계약직/대체인력 등은 비정규직입니다. 정규직 전환 가능 계약직은 현재 비정규직, 무기계약직·공무직·형태 혼재는 확인 필요입니다. 정확도 백분율은 전체 원문 정답 평가를 하지 않아 제시하지 않습니다. 다직렬 공고에는 직무별 형태/지역이 다를 수 있으므로 원문 확인이 필요합니다.

지역은 명시된 근무지에서만 판단합니다. 서울/경기/인천 이외, 미기재, 복수 지역은 기타이며 실제 표기는 보존합니다. 본사 주소로 근무지를 추정하지 않습니다. 날짜가 없는 공고 및 목록에서 사라진 공고는 접수 여부가 자동 확정되지 않습니다.

## 수집 원칙과 확장

공식 API → 공개 RSS/Atom → 검토된 기관/기업 페이지 → 검색엔진 원문 후보 순서입니다. `collector.py`의 `ADAPTERS` 레지스트리와 `sources.json` 설정을 공유합니다. 신규 사이트별 코드를 먼저 복제하지 않습니다. 조사 내역은 `SOURCE_CATALOG.md`를 참고하세요.

- LinkedIn 자동 수집 제외. 사람인·잡코리아·CATCH 직접 포털 수집 없음.
- 페이지는 검토 기록(90일 이내), HTTPS 허용 호스트/경로, robots 확인, 요청 간격 및 개수/시간 한도를 적용합니다. redirects, 지원/로그인 페이지, 첨부파일 수집은 차단합니다.
- ALIO는 [공개데이터 이용정책](https://job.alio.go.kr/right.do)을 검토했습니다. robots 404일 때 이 출처에만 공개데이터 정책에 근거한 예외를 적용합니다. 다른 실패를 허용으로 추정하지 않습니다.
- HYBE는 공개 페이지의 robots 허용 경로와 공개 방침을 검토한 메타데이터 한정 연결입니다. robots 허용이 재이용 허가의 보증은 아닙니다. 본문/지원자 정보를 재배포하지 않습니다.
- 403/429/robots 비허용 등은 우회하지 않습니다. 한 소스 실패 시 이전 데이터 보존 후 다음 소스로 진행합니다.
- 사람인: 승인 후 저장소 Settings → Secrets and variables → Actions에 `SARAMIN_ACCESS_KEY` 등록. `.github/workflows/daily-jobs.yml`에서 이미 환경변수로 연결하며 `collector.py`의 `fetch_saramin`/`parse_saramin` 및 `sources.json`의 saramin 설정이 준비되어 있습니다. 키를 코드/채팅에 넣지 마세요. Mac은 셸 환경변수로 설정합니다.
- 잡코리아: 승인·제공 명세 대기 설정만 유지합니다. 승인 후 실제 명세에 맞는 어댑터를 `ADAPTERS`에 등록하고 활성화해야 합니다. 사람인과 API 형식을 같다고 가정하지 않습니다.
- 검색엔진: 네이버 공식 검색 API 어댑터 준비. `NAVER_SEARCH_CLIENT_ID`, `NAVER_SEARCH_CLIENT_SECRET` 연결 후 허용한 공식 도메인의 원문 후보만 별도 저장합니다. 검색 결과를 확인된 채용공고로 섞거나 원문을 자동 방문하지 않습니다. 현재 키 없어 미연결입니다.

## 간호사 면허 중심 감시 기준

기업·사업장의 보건관리자/보건관리원/산업간호사/사업장 간호사에 집중합니다. 산업위생사·산업안전기사·안전관리자 자체의 채용 및 기사 자격 단독 필수 공고는 제외합니다. 보건관리자 공고에서 간호사 면허와 기사 자격이 선택 관계인 경우는 유지합니다. 면허 자격이 명시된 공고와 간호사 지원자격 확인 필요 공고를 구분합니다. 간호사 자격이 보인다는 사실이 다른 경력/학력 요건까지 충족한다는 뜻은 아닙니다. 첨부파일에만 자격요건이 있거나 보건관리자 선임 가능만 적힌 공고는 확인 필요입니다.

### API 키 없이 감시 범위 늘리기

현재 ALIO/HYBE/RSS 외에 쿠팡 계열의 Greenhouse 공개 API, DL이앤씨 공식 현장 채용, DN오토모티브와 11번가의 Greeting 목록을 매일 확인합니다. Greenhouse 공개 GET은 인증이 필요하지 않으므로 별도 키 발급이나 설정이 없습니다. 사람인과 잡코리아 API 승인 대기 상태에는 영향이 없습니다.

- 같은 플랫폼의 기업 추가: `sources.json`에 `adapter: greenhouse` + `board_token`, 또는 `adapter: greeting` + 공식 호스트/경로/접근조건 검토를 추가합니다. 개별 회사 수집기를 복제하지 않습니다.
- 게시일/마감일이 없으면 추정하지 않습니다. DL의 9999.12.31은 상시채용 표시로 처리합니다. 간호사 면허 미명시는 지원자격 확인 필요로 표시합니다.
- Greenhouse 전체 목록에서 내려간 공고는 확인한 시각을 `withdrawn_at`으로 기록합니다. 기본 화면에서 숨기며 ‘마감된 공고 포함’으로 볼 수 있습니다. 접속 실패만으로 공고를 폐쇄하지 않습니다.
- 추가 후보 조사: GitHub Actions의 ‘공개 채용 소스 일회성 접근 조사’를 수동 실행하거나 Mac에서 `python3 scripts/probe_sources.py`. robots 허용 경로만 읽고 원문 HTML은 저장하지 않습니다.

구체적인 연결/제외 근거와 실제 집계는 `SOURCE_CATALOG.md`, `COLLECTION_REPORT.md`에 기록합니다.
